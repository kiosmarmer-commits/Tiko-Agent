# Simpul P15 — JSON Canvas Obsidian-Compatible (FR-41)

Tanggal: 2026-11-14 · Branch: `vibe/simpul-p15-2a5227` · Basis: main (merge PR #21)

## Ringkasan

FR-41 dari PRD: graf vault kini dapat diekspor sebagai file **JSON Canvas**
(`.canvas`, spec jsoncanvas.org) yang bisa dibuka langsung di Obsidian —
dan dokumen canvas apa pun dapat dibaca balik (decode tervalidasi).

### Core (`packages/simpul_core/lib/src/json_canvas.dart`)

- **`JsonCanvasNode`** — 4 tipe spec (`text`, `file`, `link`, `group`) dengan
  `x/y/width/height` (sudut kiri-atas sesuai spec) dan `color` palet "1".."6".
- **`JsonCanvasEdge`** — `fromNode`/`toNode` + `fromSide`/`toSide`/`label`/`color`.
- **`JsonCanvasDocument`** — `encode()` (pretty-print, kunci persis spec) dan
  `decode()` yang menolak dokumen tidak valid dengan `JsonCanvasException`
  berbahasa Indonesia: bukan objek, tanpa `nodes`, node tanpa `id`, tipe tak
  dikenal, koordinat bukan angka, edge tanpa `fromNode`/`toNode`, JSON rusak.
- **`VaultCanvas.fromNotes(...)`** — ekspor graf vault: tiap catatan menjadi
  node `file` (path vault-relatif, ukuran 260×120), posisi dari force layout
  (spread ×2, dinormalisasi ke ≥0), tiap tautan ter-resolve menjadi edge,
  warna node deterministik per folder via palet spec (FNV-1a hash → "1".."6";
  catatan di root tanpa warna).

### CLI (`apps/simpul`)

- `simpul canvas <vault> [--out path] [--iterations N]` — menulis
  `<vault>/graph.canvas` (default) secara atomik; sadar enkripsi (membaca
  `SIMPUL_PASSWORD` untuk vault terkunci, sama seperti perintah lain);
  mencetak ringkasan JSON `{canvas, nodes, edges}`.
- Help text diperbarui.

## Keputusan desain

- **Node type `file`** (bukan `text`): Obsidian merender kartu dengan preview
  isi catatan dan klik membuka catatan — kompatibilitas maksimal.
- **Posisi dari force layout** yang sama dengan UI graf (GRA), bukan grid:
  hasil ekspor langsung terbaca sebagai peta keterkaitan di Obsidian.
- **Warna palet spec** ("1".."6"), bukan hex bebas, agar konsisten dengan
  tema Obsidian dan tetap deterministik lintas sesuai (sama dengan GRA-15).
- **Decode tervalidasi tapi longgar terhadap field ekstra** — field tak dikenal
  diabaikan, sesuai semangat spec (forward-compatible).
- Bridge MCP belum mendapat tool canvas (metadata graf saja, bukan konten
  catatan); dapat ditambah belakangan bila diperlukan.
