## Quadtree culling (GRA-R02)

- `QuadtreeIndex.build(x, y)` membangun point quadtree atas buffer posisi
  `Float32List` milik `GraphCsr` (GRA-D01/L06) tanpa salinan data.
- `queryRegion(minX, minY, maxX, maxY)` mengembalikan node id dalam persegi
  tertutup, terurut — diverifikasi setara brute-force pada 200 titik.
- `hitTest(px, py, radius)`: node terdekat dalam radius (inklusif), tie ke id
  terkecil — untuk hover/klik (GRA-13).
- Daun berkapasitas 8; subdivisi digagalkan secara aman bila semua titik
  identik (koordinat duplikat) sehingga tidak ada loop tak hingga. Bug yang
  ditemukan saat iterasi test: titik baru tercatat dua kali (sekali di daun
  penuh, sekali di bucket hasil subdivisi) → kapasitas kini dicek sebelum
  insert.

## Layout di isolate (NFR-S02, GRA-L01, GRA-L06, NFR-S08)

- `IsolateLayout.simulate(graph)` menjalankan `ForceLayout.simulate` penuh di
  isolate terpisah via `Isolate.run` — UI thread tidak pernah memikul simulasi
  (NFR-S02, frame budget 16 ms).
- Topologi (offsets/targets) dan posisi dikirim ke isolate dengan
  `TransferableTypedData`, hasil dikembalikan juga sebagai buffer transferable
  (NFR-S08); posisi `GraphCsr` pemanggil di-refresh in-place sehingga warm
  start (GRA-L02) tetap berfungsi.
- Determinisme dipertahankan: hasil isolate identik bit-per-bit dengan
  simulasi langsung (diverifikasi test).

## Layout multi-level (GRA-L04)

- `MultiLevelLayout.simulate`: coarsening memakai komunitas Louvain (P2),
  simulasi di graf kasar, prolongasi posisi ke tiap node asal (spiral
  golden-angle di sekitar pusat komunitasnya), lalu refine warm-start.
- Deterministik penuh; fallback ke simulasi langsung bila tidak ada
  penggabungan yang mungkin (`communityCount >= nodeCount`).
- Graf kasar dibangun dengan `GraphCsr.fromEdges` (edge antar-komunitas
  ter-dedup, undirected-normalized) — juga berguna untuk test.
