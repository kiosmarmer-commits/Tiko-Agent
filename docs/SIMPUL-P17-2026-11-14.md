# Simpul P17 — Sinkronisasi Terenkripsi End-to-End (SEC-20..22)

Tanggal: 2026-11-14 · Branch: `vibe/simpul-p17-2a5227` · Basis: main (merge PR #23)

## Ringkasan

Item PRD terakhir yang actionable: **bundle sinkronisasi end-to-end** —
seluruh vault (catatan + artefak indeks JSON) disegel menjadi satu file
portabel `.simpulbag` yang hanya bisa dibuka dengan password. Plaintext tidak
pernah menyentuh saluran transfer; model sinkronisasi tetap local-first tanpa
server.

## Format (`SMPLBAG1`, berversi)

```
magic 'SMPLBAG1' (8) | version (1) | keyCrateLen (4) | keyCrate | dataCrate
```

- **keyCrate** — format crate standar (`SMPLCRT1`): kunci vault acak baru
  dibungkus KEK Argon2id dari password (SEC-05/07).
- **dataCrate** — arsip berisi semua entri, dienkripsi XChaCha20-Poly1305
  (SEC-03) dengan kunci vault tersebut, nonce acak per ekspor (SEC-08).
- **Arsip** (plaintext di dalam dataCrate): `count(4)` lalu per entri
  `pathLen(2) | path | contentLen(8) | content`.

## API (`vault_bundle.dart`)

- `VaultBundle.exportBundle(vault, {password, outPath, crypto})` — membaca
  catatan `.md` (skip folder tersembunyi) + artefak `.simpul/`
  (index.json, vectors.json, graph_cache.json, ai-permissions.json); file
  terenkripsi didekripsi in-memory dulu (butuh `crypto` bila vault terkunci —
  fail-closed tanpa kunci). `index.db` dan `vault-key.crate` sengaja tidak
  ikut: db adalah artefak turunan (tujuan menjalankan ulang `simpul index`),
  dan tiap perangkat punya hierarki kuncinya sendiri.
- `VaultBundle.importBundle(bagPath, {password, outDir})` — validasi magic +
  versi, buka keyCrate dengan password, dekripsi dataCrate, **tolak entri
  path traversal** (`..`, absolut) sebelum satu byte pun ditulis, tulis
  atomik (tmp+rename).

## CLI

- `simpul bundle-export <vault> [--out path]` — default
  `<vault>.simpulbag`; ringkasan JSON `{bundle, files, bytes}`.
- `simpul bundle-import <bag> --out <dir>` — tulis vault plaintext (m0) di
  tujuan; pesan mengarahkan `simpul lock` bila perlu.
- Help text diperbarui.

## Keputusan desain

- **Tanpa server, tanpa jaringan** — transport (USB, syncthing, rsync, cloud)
  adalah urusan pengguna; keamanan end-to-end datang dari segel kripto,
  bukan dari saluran. Ini konsisten dengan prinsip local-first PRD.
- **Satu folder = satu bundle mandiri** — tidak ada delta/incremental antar
  bundle pada batch ini: sederhana, auditable, dan cukup untuk backup/
  migrasi perangkat. Delta sync antar perangkat (merge dua sisi) adalah
  backlog terpisah bila dibutuhkan.
- **Path traversal ditolak sebelum menulis** — bundle dari pihak ketiga tidak
  bisa menimpa file di luar folder tujuan.
