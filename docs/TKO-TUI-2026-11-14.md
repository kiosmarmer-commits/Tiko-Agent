# TKO-TUI — Engine TUI Bersama untuk Tiko (P19, 2026-11-14)

## Latar

Pertanyaan: apakah `tiko setup` sudah punya TUI interaktif seperti Hermes?

Kondisi sebelum batch ini:

- `tiko setup --interactive` **sudah ada** (wizard provider, API key SecretRef,
  gateway Telegram/Discord, email SMTP+IMAP) tetapi masih line-based
  `readLineSync()` — tanpa editing per karakter, tanpa history, tanpa autocomplete.
- `tiko chat` REPL juga line-based.
- TUI penuh (raw mode, multiline, history, autocomplete) hanya ada di
  `simpul tui` (P18) dengan engine yang hidup di `apps/simpul/lib/tui/`.

Hermes menyediakan TUI interaktif pada CLI agent-nya: line editor raw-mode ANSI,
editing multiline, history persisten, autocomplete perintah. Tiko belum setara.

## Solusi: paket bersama `packages/tiko_tui`

Engine TUI dipindah ke paket workspace `tiko_tui` (tanpa dependency runtime)
sehingga dipakai bersama oleh `apps/tiko` dan `apps/simpul`:

| Modul | Isi |
| --- | --- |
| `line_editor.dart` | `decodeKeys` (ANSI CSI A/B/C/D/H/F, ~1/~3/~4, kontrol, UTF-8), `LineEditor` (kursor, gerak kata, kill-ring Ctrl+A/E/K/U/W, yank, history naik/turun dengan draft terjaga, siklus autocomplete Tab), `MultilineBuffer` (backslash lanjutan + blok `/begin`…`/end`) |
| `history_store.dart` | `TuiHistoryStore` — persistensi riwayat per baris, limit 500 |
| `prompt_runner.dart` | `PromptRunner` — prompt wizard interaktif: `prompt` (default/required), `confirm` (y/N), `readLine` dengan completions; raw mode dengan autodetect + fallback line-mode; Ctrl+C/D → `PromptAborted` |
| `session.dart` | `TuiSession` — REPL generik dengan handler terinjeksi: banner, prompt, multiline, autocomplete, warna ANSI (hormati `NO_COLOR`/`TERM=dumb`), fallback line-mode, riwayat persisten |

Semua komponen dapat diuji tanpa TTY: `scriptedLines` (line mode),
`inputStream` (byte mentah untuk raw mode), `out` (StringSink), dan
`forceLineMode` dapat diinjeksi.

## Perubahan

### `apps/tiko`

- `tiko chat` (embedded dan remote-daemon): REPL loop diganti `TuiSession`
  dengan handler `/quit` `/exit` `/doctor` `/status`, completer
  `_chatCompleter` (siklus Tab pada 4 perintah), riwayat persisten di
  `<dataDir>/tui-history.txt`, prompt `you> `.
- `tiko setup --interactive`: closure prompt/confirm lokal dihapus, diganti
  `PromptRunner` — kini wizard mendapat editing per karakter, history, dan
  Tab autocomplete pada daftar tipe provider (mock, ollama_native, openai,
  deepseek, anthropic, gemini, openai_compat, openai_responses,
  azure_openai, bedrock). `PromptAborted` (Ctrl+C/EOF) ditangani graceful
  dengan pesan "Setup dibatalkan." dan exit code 130.

### `apps/simpul`

- `lib/tui/line_editor.dart` dan test-nya dihapus; `repl.dart` menjadi adapter
  tipis `runTui(vault)` → `TuiSession`; `commands.dart` mengimpor
  `TuiOutcome`/`TuiHistoryStore` dari `tiko_tui`. Perilaku tidak berubah.

## Catatan desain

- Raw mode diaktifkan hanya bila tersedia (`stdin.hasTerminal` + probe
  set/restore lineMode); pipa dan CI otomatis jatuh ke line-mode sehingga
  skrip dan test tetap deterministik.
- `StreamIterator` dibuat sekali per instance (`stdin` single-subscription)
  sehingga wizard multi-prompt dan REPL aman.
- EOF pada raw mode (`Ctrl+D` buffer kosong) mengakhiri REPL dengan rapi;
  pada wizard melempar `PromptAborted` yang ditangani pemanggil.
