# D1 — GenUI: Antarmuka Generatif yang Aman (DSL → Widget Flutter)

Tanggal: 2026-11-17 · Status: Implemented · PR: vibe/genui-dsl-563120

## Ringkasan

Tiko-Agent kini bisa **merender antarmuka interaktif nyata** — bukan hanya teks.
Agen menghasilkan spesifikasi UI terstruktur lewat tool `render_ui`; spesifikasi
divalidasi fail-closed dan mengalir sebagai blok fenced ` ```genui ` di teks
chat; klien Flutter merendernya menjadi widget nyata (dashboard, grafik,
formulir, tombol aksi). Ini adalah diferensiator utama vs Hermes Agent
(Python/terminal): agen yang membangun UI-nya sendiri.

## Arsitektur

```
LLM → tool render_ui (validasi fail-closed, agent_core)
    → konten tool: blok ```genui (JSON) di teks chat
    → transport biasa (WS stream / HTTP) — TANPA perubahan protokol
    → Flutter: GenUiMessageView memisahkan teks & blok (splitGenUiSegments)
    → GenUiView merender node → widget native
    → aksi/form dikirim balik: chat.send('/ui <actionId> <json-values>')
```

## Komponen

| Komponen | Lokasi | Peran |
|---|---|---|
| `GenUiSpec`, `GenUiNode` | `packages/agent_core/lib/src/genui.dart` | Parser + validator fail-closed (pure Dart, tanpa Flutter) |
| `extractGenUiBlocks`, `splitGenUiSegments` | sama | Pisahkan blok ` ```genui ` dari teks chat |
| `RenderUiTool` | `packages/agent_tools/lib/src/render_ui_tool.dart` | Tool `render_ui` (risk low) untuk agen |
| `GenUiMessageView`, `GenUiView` | `apps/agent_flutter/lib/ui/gen_ui_view.dart` | Renderer widget + form state + onAction |
| Registrasi | `tiko_runtime.dart` | `..register(const RenderUiTool())` |
| Integrasi chat | `apps/agent_flutter/lib/main.dart` | Bubble asisten memakai `GenUiMessageView`; aksi → `chat.send('/ui ...')` |

## Grammar tertutup (allowlist)

| Tipe | Kunci | Batas |
|---|---|---|
| `section` | title, children[] | ≤ 20 children |
| `text` | text, style (heading\|body\|mono) | ≤ 2000 char |
| `metric` | label, value (string\|num), delta? (num) | label ≤ 200 |
| `chart` | chart (bar\|line), points[{label,value}] | ≤ 31 titik |
| `form` | id, title?, fields[{name,label,kind,options?,initial?}] | ≤ 8 field; select ≤ 16 opsi |
| `actions` | buttons[{id,label,style}] | ≤ 4 tombol; style normal\|danger |
| `divider` | — | — |

Batas global: depth ≤ 8, ≤ 100 node, ≤ 4 blok per pesan. Identifier
(`id`, `name`, button id) wajib `[A-Za-z0-9_.-]{1,64}`. Kunci/tipe tak dikenal,
karakter kontrol, duplikat, dan pelanggaran batas **ditolak** dengan
`FormatException` berpesan Indonesia — agen dapat memperbaiki dan memanggil
ulang.

## Keamanan

- **Tidak ada widget arbitrer**: LLM tidak bisa memilih widget/handler apa pun
  di luar allowlist — permukaan serangan "UI injection" tertutup.
- **Fail-closed ganda**: sisi agen (tool) dan sisi klien (renderer) memvalidasi;
  blok rusak/tak valid ditampilkan sebagai teks, bukan UI setengah jadi.
- **Tidak ada eksekusi**: spesifikasi murni data; aksi hanya ID yang dikirim
  balik ke agen sebagai pesan `/ui` — host tidak pernah mengeksekusi sesuatu
  dari spesifikasi.

## Batasan (jujur)

- Chart masih primitif (bar via progress bar, line via CustomPaint sederhana);
  grafik kaya (fl_chart) bisa menyusul tanpa mengubah spesifikasi.
- Aksi/form dikirim sebagai pesan `/ui <id> <json>` ke agen — runtime agentd
  belum punya handler khusus untuk pola ini (agen tetap menerima pesannya
  sebagai teks biasa dan bisa menafsirkannya; handler eksplisit = lanjutan).
- Renderer baru terintegrasi di klien Flutter; klien CLI/web menampilkan blok
  sebagai teks (aman, tetap berfungsi).
