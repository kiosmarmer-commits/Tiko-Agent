# Simpul Batch P8 — Layer Visualisasi Graf Flutter (GRA-R03/R04)

Tanggal: 2026-11-13. Batch kedelapan implementasi PRD "Simpul", menutup gap
terbesar yang tersisa: tampilan graf vault di Flutter client. Batch ini hanya
mungkin setelah Flutter SDK terpasang di lingkungan pengembangan (Flutter
3.50.0 stable + Dart 3.14.0 di sandbox; CI tetap 3.47.5).

## Cakupan

1. **`GraphViewController`** (`apps/agent_flutter/lib/ui/graph_view.dart`) —
   memuat vault via `VaultScanner`, membangun `GraphCsr` (GRA-D01/D02),
   layout Barnes-Hut dengan warm start dari cache bersama CLI (GRA-L02/
   NFR-S09), quadtree untuk culling + hit-test (GRA-R02), derajat per node,
   dan komunitas Louvain (GRA-L05) untuk agregasi LOD.
2. **`GraphView` widget** — `InteractiveViewer` (pan/zoom, GRA-12) +
   `CustomPainter`:
   - **GRA-R01**: node digambar batch via `drawRawPoints` (dikelompokkan per
     ukuran radius), bukan `drawCircle` per node.
   - **GRA-R04**: edge digambar satu panggilan `PointMode.lines` batch;
     ketebalan disesuaikan zoom.
   - **GRA-R03 (LOD)**: zoom jauh (< 0.35) → satu titik per komunitas
     Louvain di centroid + edge agregat antar komunitas; zoom menengah →
     node + edge individual; zoom dekat (≥ 0.9) → + label.
   - **GRA-R02**: culling viewport — hanya node/edge dalam viewport (+margin)
     yang digambar; hit-test hover/klik via quadtree.
   - **GRA-10**: radius node ∝ √derajat (clamp 4–18). **GRA-11**: edge tipis.
   - **GRA-13**: hover menyorot node + tetangganya (highlight biru).
   - **GRA-14**: klik membuka isi catatan (dialog, desktop lokal).
   - **GRA-15**: warna deterministik per folder (hash FNV-1a → HSL hue).
   - **GRA-18**: label muncul saat zoom dekat, dibatasi 60 label teratas
     (derajat tertinggi) + fokus hover/ seleksi agar tidak overdraw.
3. **`SimpulGraphPage`** — halaman lengkap: path vault + tombol Muat, field
   filter (GRA-03: substring path/judul atau `tag:x` termasuk tag nested),
   status (node/edge/iterasi/warm start), dan entry di halaman More.
4. **`layout_cache.dart` di simpul_core** — helper cache layout dinaikkan
   dari CLI ke core (`graphFingerprint`, `layoutCacheVersion`,
   `layoutCacheKind`, `applyWarmStart`, `openVaultCacheStore`) sehingga CLI
   dan Flutter memakai satu implementasi; warm start lintas keduanya
   (layout dari CLI dipakai UI dan sebaliknya).
5. **simpul_core kini web-safe** — `SqliteVaultIndex` dipisah ke
   `vault_index_sqlite.dart` dengan conditional export
   (`if (dart.library.ffi)`); di web dipakai stub fail-closed (`tryOpen`
   selalu null → fallback `JsonVaultIndex`). Tanpa ini `flutter build web`
   gagal karena `dart:ffi` tidak tersedia. Perilaku VM tidak berubah.

## Keputusan desain

- **Lokal-first, bukan via agentd** — graf membaca vault langsung dari disk
  (sama seperti CLI); halaman ini untuk desktop/web dengan akses folder.
- **Filter merender, bukan me-layout ulang** — posisi tetap stabil saat
  filter berubah; node tak cocok disembunyikan, edge hanya digambar bila
  kedua ujungnya terlihat.
- **LOD via komunitas Louvain yang sudah dihitung** — agregasi zoom jauh
  memakai hasil GRA-L05 tanpa pass tambahan.
- **Label dibatasi 60** — `TextPainter` per label mahal; kandidat diurutkan
  derajat tertinggi, plus fokus hover/seleksi selalu berlabel.
- **`testWidgets` berjalan di FakeAsync** — I/O nyata (`VaultScanner.scan`)
  harus dilakukan di `setUpAll` (zona async biasa), bukan di dalam
  `testWidgets`; inilah penyebab test widget pertama menggantung.
