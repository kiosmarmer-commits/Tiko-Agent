## MCP "Simpul Bridge" (AI-44)

- `simpul serve <vault> [--token T]`: server MCP **stdio** — JSON-RPC 2.0
  newline-delimited di stdin/stdout, **tanpa listener jaringan sama sekali**
  (lebih ketat dari "localhost/socket lokal" AI-44). Kompatibel dengan
  `mcpServers` yang sudah ada di konfigurasi agent_core: cukup daftarkan
  command `dart run bin/simpul.dart serve <vault>`.
- `initialize` (protocolVersion 2024-11-05), `tools/list`, `tools/call`,
  `ping`; notification diabaikan; JSON rusak → error -32700 tanpa mati.
- Tujuh tool fail-closed: `search`, `semsearch`, `health`, `backlinks`,
  `read_note`, `clusters`, `suggest_links` — vektor AI (RAG "tanya vault",
  AI-21) kini bisa menjangkau vault Simpul lewat antarmuka standar.
- `read_note` menolak path traversal (canonicalize + isWithin), memotong
  output di 20.000 karakter.
- `--token`: bila diset, setiap request wajib membawa
  `params._meta.token` yang cocok, selain itu error -32001 (fail-closed).
- Kegagalan tool dikembalikan sebagai result `isError: true` (konvensi MCP),
  bukan error protokol.

## Cache graf ber-versi (NFR-S09, GRA-D04)

- Interface `GraphCacheStore`: `saveGraphCache(kind, version, payload)` /
  `loadGraphCache(kind, version)` — payload hanya dikembalikan bila versi
  cocok; entri basi tidak pernah tersaji.
- Backend SQLite: tabel `graph_layout` (kind PRIMARY KEY, version, payload
  JSON, created_at) — posisi, klaster, dan versi tata letak tersimpan di
  SQLite persis seperti GRA-D04.
- Backend JSON: sidecar `graph_cache.json` di `.simpul/`, tulis atomik
  tmp+rename mengikuti pola index.json.
- Konsumsi lanjutan (layer Flutter GRA-R03, dedup recompute) tinggal memanggil
  API ini; belum diaktifkan otomatis di CLI agar perilaku command existing
  tidak berubah.
