# Simpul Batch P6 — Integrasi Ollama ke Pipeline, Cache Layout Otomatis, Vektor Inkremental

Tanggal: 2026-11-13. Batch keenam implementasi PRD "Simpul", menutup tiga gap
yang teridentifikasi setelah P5: embedder Ollama yang belum terhubung ke
pipeline utama, cache graf yang belum dipakai otomatis oleh CLI, dan sync
inkremental yang belum memperbarui vektor.

## Cakupan

1. **`ReplayEmbedder`** (`packages/simpul_core/lib/src/embedding.dart`) —
   jembatan embedder async → sinkron: teks → vektor pre-computed dipetakan
   eksak; teks asing → `StateError` (fail-closed, tidak pernah vektor nol
   diam-diam). Dipakai CLI agar `InMemorySemanticIndex` dan `HybridSearcher`
   yang sinkron tetap tidak tersentuh saat memakai Ollama (AI-03).
2. **`InMemorySemanticIndex.storedModelVersion(path)`** — membaca header
   `model_version` file vektor tanpa memuat seluruh entri; null saat file
   tidak ada/korup. Dasar pemeriksaan mismatch fail-closed (AI-13).
3. **CLI `index --embed --embedder ollama [--model M] [--base-url U]
   [--dim N]`** — chunk di-embed batch (32/request) lewat `OllamaEmbedder`,
   dibungkus `ReplayEmbedder`, lalu jalur `replaceAll` yang sama. Output
   kini mencantumkan `model`.
4. **CLI `semsearch` / `search --hybrid --embedder ollama`** — vektor kueri
   dihitung via Ollama; sebelum membuka file vektor, `model_version` tersimpan
   diverifikasi — mismatch → error jelas + exit non-zero (fail-closed), bukan
   pencarian diam-diam kosong.
5. **Cache layout otomatis (GRA-L02, NFR-S09, GRA-D04)** — `simpul layout`
   kini memuat cache ber-versi dari `GraphCacheStore` (SQLite tabel
   `graph_layout` atau sidecar `graph_cache.json`) sebagai warm start, dan
   menyimpan hasilnya kembali. Kunci versi =
   `<algo-v1>:<iterations>:<fingerprint-graf>`; fingerprint FNV-1a atas
   struktur node+edge sehingga perubahan topologi vault otomatis
   menginvalidasi. Payload berbentuk salah diabaikan (cold start), tidak
   pernah merusak simulasi. `--no-cache` mematikan. Warm start berlaku untuk
   jalur default dan `--isolate` (hasil identik bit-per-bit); `--multi-level`
   ikut menulis cache. Output mencantumkan `warm_start`.
6. **Vektor inkremental di `simpul sync` (NFR-S05/08, AI-12)** —
   `VaultSync.apply` menerima `semanticFactory(List<ScannedNote> changed)`:
   factory menerima persis catatan yang berubah (embedder async seperti
   Ollama hanya meng-embed chunk itu), chunk tak berubah dilewati lewat hash
   (AI-12), catatan terhapus di-drop dari indeks vektor. Index yang dibuat
   factory ditutup oleh `VaultSync.apply`. CLI melaporkan `vectors`:
   `absent` / `unchanged` / `updated` / `skipped_model_mismatch` — mismatch
   tidak merusak sync indeks teks, vektor dibiarkan apa adanya (fail-closed).

## Keputusan desain

- **`ReplayEmbedder`, bukan refactor `SemanticIndex` jadi async** — seluruh
  call-site sinkron (`InMemorySemanticIndex`, `HybridSearcher`, saran tautan)
  tetap tanpa perubahan; hanya CLI yang tahu tentang async. Vektor kueri
  dihitung async dulu, lalu masuk lewat adapter.
- **Batch 32 teks/request** untuk Ollama — request tunggal raksasa berisiko
  timeout 30s default pada vault besar; 32 menjaga latensi per request.
- **Fingerprint struktur graf, bukan mtime vault** — mtime menyentuh ulang
  cache untuk perubahan konten yang tidak mengubah graf; fingerprint hanya
  berubah saat node/edge berubah, persis yang mempengaruhi layout.
- **Factory dipanggil hanya saat ada perubahan/penghapusan** — sync tanpa
  perubahan tidak membuka file vektor sama sekali.
- **`skipped_model_mismatch` bukan error** — sync teks tetap sah tanpa vektor;
  menggagalkan seluruh sync karena vektor akan melanggar prinsip
  lokal-first (indeks teks adalah sumber kebenaran utama).

## Verifikasi (sandbox, 2026-11-13)

- `dart analyze --fatal-warnings` bersih di 15 member.
- `dart test` hijau: simpul_core 84 lulus / 4 skip (sqlite), apps/simpul 7,
  seluruh member lain tetap hijau.
- Test baru `test/p6_integration_test.dart` (4 kasus): ReplayEmbedder
  fail-closed, `storedModelVersion`, sync inkremental (hanya chunk berubah
  di-embed — dibuktikan dengan ReplayEmbedder yang melempar pada teks tak
  dikenal), factory null tidak merusak sync.
- Smoke CLI end-to-end: `index --embed` (model hashing-v1 tercatat), `layout`
  run-1 `warm_start:false` → run-2 `warm_start:true` (iterasi turun 49→1,
  energi lebih rendah), `semsearch` OK, `sync` perubahan → `vectors:updated`,
  mismatch model → `vectors:skipped_model_mismatch` + `semsearch` exit 1
  dengan pesan jelas, `eval --embedder ollama` tanpa server → exit 1.

## Traceability PRD

- **AI-03**: Ollama kini menjangkau `index`, `semsearch`, `search --hybrid`,
  `sync` — bukan hanya `eval`.
- **AI-12**: hash-based skip di `upsert` kini terpakai nyata lewat sync
  inkremental; batch 32/request.
- **AI-13**: pemeriksaan `storedModelVersion` fail-closed di seluruh jalur
  baca vektor.
- **GRA-L02 / NFR-S09 / GRA-D04**: cache layout ber-versi dipakai otomatis
  sebagai warm start.
