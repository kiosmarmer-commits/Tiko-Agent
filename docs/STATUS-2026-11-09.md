## 3. Algoritma penting

1. **ReAct** dengan budget iterations/tokens/wall clock/tool calls, loop detection tool+args, compaction dan optional reflection.
2. **Tier routing** 1–3; decision model jika enabled, heuristic fallback, provider health scoring dan failover.
3. **Circuit breaker** half-open satu probe, release slot jika stream dibatalkan; provider fallback memiliki error `all_breakers_open`.
4. **Retrieval** FTS5/BM25 plus optional vector candidates dan RRF (`k=60`); JSON fallback tidak menggunakan SQLite FTS.
5. **Skill matching** semantic cosine bila embedder tersedia atau lexical Jaccard; reliability dengan age decay.
6. **Skill synthesis/evaluation** S_eval, draft synthesis, scan, isolated golden evaluation, approval eksplisit dan ledger durabel.
7. **Calculator** exact decimal BigInt untuk operasi utama; IRR merupakan jalur numerik approximate; kalkulator runtime dieksekusi melalui isolate sandbox.
8. **Scheduler** cron local-wall-time via IANA tzdata, fold pilih kemunculan pertama, delivery at-least-once dengan ack/retry durabel.

## 5. Batasan dan open gaps

- MCP Streamable HTTP belum menyediakan GET SSE server-initiated, HTTP retry/backoff dan OAuth dynamic client registration.
- Router `ProviderHealth` dan `agent_providers.CircuitBreaker` masih dua state mechanism.
- Client Flutter memiliki beberapa method yang mengubah HTTP error menjadi empty list/map; ini berpotensi menyamarkan error. Validasi token/URI dan lifecycle WebSocket perlu test lebih kuat.
- Feedback skill end-to-end dari UI/chat belum terhubung penuh; metrik di ledger bersifat best-effort fire-and-forget.
- Vector backend default brute-force dan belum benchmark skala besar.
- Sandbox OS tergantung host; Termux/proot bukan isolasi kuat.
- Scheduler delivery bersifat at-least-once sehingga duplikasi mungkin pada crash di jendela send/ack.
- Benchmark isolate pada perangkat Termux nyata belum tersedia.
- TASK-CALC-24..35 belum didefinisikan di repo; jangan mengarang scope.
- Integrasi gateway nyata perlu smoke test akun/token masing-masing.
