## Arsitektur

### Editor page (`apps/agent_flutter/lib/ui/note_editor.dart`)

- `List<NoteEditor> tabs` + `activeTab`; `_open()` mendaftarkan editor baru
  sebagai tab (atau me-reload tab yang sudah ada untuk path sama);
  `_openPath` mengaktifkan tab bila sudah terbuka — perubahan tak tersimpan
  tidak lagi memblokir pindah catatan karena tiap tab menyimpan state sendiri.
- `_activateTab(i)`: sinkronkan `textField`/`dirty`/`pathField` dari tab tujuan;
  `_closeTab(i)`: simpan dulu bila kotor (atomik), lalu hapus dan aktifkan
  tetangga; tab terakhir ditutup → editor kosong kembali.
- `_editorPane()` diekstrak agar mode biasa dan split memakai pane yang sama.
- Param baru `resourceStats` (diteruskan ke panel chat) dan `initialTabs`
  (injeksi test — menghindari I/O nyata di dalam FakeAsync).

### Panel chat (`ui/note_chat_panel.dart`)

- Param `resourceStats` + `snapshotOverride` (injeksi test); `Timer.periodic`
  2 detik menghitung CPU% dari delta ticks antar snapshot; timer dibatalkan
  di `dispose`. Tanpa `resourceStats`, tidak ada timer (widget test lama aman).

### Core (`packages/simpul_core/src/resource_monitor.dart`)

- `cpuTicks` dari field 12–13 `/proc/self/stat` (setelah `)`, indeks 11–12);
  `cpuPercent` null-safe: null bila ticks hilang/berkurang atau interval ≤ 0.

  PRD menandainya best-effort; CPU proses + load average + RAM sudah
  mencakup kebutuhan indikator AI-U03.

  diaktifkan dari shell (desktop/web) agar mode test dan perangkat lemah
