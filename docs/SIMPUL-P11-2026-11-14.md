# Simpul Batch P11 — Enkripsi M2 (Per-Folder) & M3 (Vault Penuh)

Tanggal: 2026-11-14. Batch kesebelas implementasi PRD "Simpul", melanjutkan
fase enkripsi dari P9 (M1) ke **Mode M2** (catatan di folder terpilih) dan
**Mode M3** (seluruh catatan vault), sesuai `06-enkripsi.md` (SEC-01 migrasi
bertahap M0→M1→M2→M3).

## Komponen baru / berubah

1. **`vault_modes.dart`** (simpul_core, baru) — `VaultModes.lock/unlock/status`
   + `VaultEncryptionMode`:
   - `lock(vault, {password, mode, folders})` — membuat kunci vault (crate
     Argon2id + XChaCha20-Poly1305, primitif `cryptography` yang sama dengan
     P9), mengenkripsi artefak indeks (M1+) lalu catatan `.md` (M2: hanya
     folder terpilih; M3: seluruh vault, folder tersembunyi tetap dilewati),
     menulis `.simpul/vault-key.crate` + penanda `vault-mode.json`
     (`{mode, kdf, folders?, created_at}`).
   - `unlock(vault, {password})` — dekripsi balik **semua** file terenkripsi
     (indeks + catatan, mode-agnostik), hapus crate + penanda.
   - `status(vault)` — mode, KDF, folder terenkripsi (M2), jumlah catatan
     terenkripsi vs total, status per file indeks.
   - Backend SQLite ditolak saat lock (SQLCipher belum tersedia) — pindah dari
     CLI ke core agar semua pemanggil fail-closed.
2. **`vault_scanner.dart`** — parameter `crypto`: catatan terenkripsi
   didekripsi in-memory sebelum parsing; **tanpa kunci melempar
   `VaultCryptoException`** (fail-closed, bukan parsing ciphertext).
   `contentHash` dihitung dari plaintext sehingga hash stabil antara vault
   polos dan terenkripsi (sync inkremental tetap benar).
3. **`vault_sync.dart`** — meneruskan `crypto` ke diff.
4. **CLI** (`apps/simpul`):
   - `simpul lock <vault> [--mode m1|m2|m3] [--folders a,b]`
   - `simpul unlock <vault>` — kini juga mendekripsi catatan.
   - `simpul vault-status <vault>` — mode aktual dari penanda + hitungan
     catatan terenkripsi.
   - Semua perintah yang memindai vault (`index`, `layout`, `culling`,
     `clusters`, `suggest-links`, `suggest-tags`, `sync`) meneruskan crypto.
5. **Bridge** (`apps/simpul/lib/bridge.dart`):
   - `read_note` mendekripsi catatan terenkripsi; tanpa kunci → `isError`
     fail-closed.
   - `clusters` dan `suggest_links` memindai dengan crypto.
   - `SimpulBridge` menerima `password` opsional (menggantikan
     `SIMPUL_PASSWORD`) agar host tertanam bisa membuka vault terkunci tanpa
     menyentuh environment proses.

## Verifikasi

- `dart analyze` bersih di `packages/simpul_core` dan `apps/simpul`.
- `dart test` `packages/simpul_core`: 138 lulus (8 test baru
  `vault_modes_test.dart`: M1/M2/M3, scan dengan/tanpa kunci, hash stabil,
  unlock byte-for-byte, password salah, error argumen/state).
- `dart test` `apps/simpul`: 15 lulus (1 test baru: `read_note` pada vault M3
  terkunci → `isError` tanpa password, plaintext dengan password; `clusters`
  bekerja dengan password).
- Smoke CLI end-to-end (vault sintetis 50 catatan):
  `lock --mode m2 --folders catatan_vault` → 50 catatan + index.json
  terenkripsi; `vault-status` → m2, encrypted_notes 50/50; `index` dengan
  `SIMPUL_PASSWORD` berhasil, tanpa password gagal ("vault terkunci");
  `unlock` mengembalikan seluruh file polos + mode m0.

## Limitasi (backlog)

- SQLCipher/SQLite terenkripsi belum (backend SQLite tetap ditolak pada vault
  terkunci).
- SEC-06 (Shamir), SEC-16 (auto-lock UI), SEC-20..22 (sync terenkripsi E2E)
  belum.
- M2 mengenkripsi per file dengan DEK acak per file (bukan per-folder key);
  granularitas akses tetap per-folder lewat daftar folder di penanda mode.
