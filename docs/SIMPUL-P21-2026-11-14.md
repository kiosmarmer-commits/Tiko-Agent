## Arsitektur

### Core (`packages/simpul_core`)

- **`src/note_template.dart`**
  - `NoteTemplate.render(body, {title, path, now, extraVars})`: substitusi
    `{{title}}`, `{{date}}` (yyyy-MM-dd), `{{time}}` (HH:mm), `{{path}}`;
    variabel tak dikenal dibiarkan utuh (kompatibel plugin pihak ketiga);
    `extraVars` menimpa built-in.
  - `NoteTemplate.sanitizeFileName`: buang karakter ilegal `\/:*?"<>|#^[]`.
  - `TemplateStore.listTemplates/read/create`: template per-vault di
    `.simpul/templates/*.md`; vault segar = daftar kosong (bukan error).
- **`src/vault_transfer.dart`**
  - `VaultImporter.importFolder(source, dest, {format})`: salin `.md` +
    lampiran, lewati `.git/.obsidian/.trash/.simpul/.joplin` dan file sementara;
    path relatif dipertahankan (round-trip Obsidian lossless).
    - `notion`: strip sufiks uuid 32-hex pada nama file (`Page <uuid>.md` menjadi
      `Page.md`), label tautan, dan URL (`Page%20<uuid>`); duplikat nama
      dipecah `Note.md`, `Note 2.md`, ...
    - `logseq`: halaman diflatten ke `pages/*.md`, block ref `((id))` menjadi
      `` `block:id` `` (dihitung `linksRewritten`).
    - `joplin`: salin folder ekspor Markdown apa adanya.
  - `VaultExporter.noteToHtml(markdown, {title})`: subset Markdown menjadi HTML
    mandiri (heading 1-6, code fence, blockquote, list, checkbox, bold/italic/
    inline code, wikilink menjadi `<span class="wikilink" data-target>`, md link,
    escape HTML aman).
  - `VaultExporter.graphToJson(GraphCsr)`: `{"nodes":[{id,x,y}],
    "edges":[{source,target}]}` (kompatibel Obsidian graph JSON).
  - `VaultExporter.graphToGraphml(GraphCsr)`: GraphML dengan `<key>` x/y.

### CLI (`apps/simpul`)

- `template list <vault>` / `template create <vault> <nama>` (isi dari stdin).
- `import --from DIR [--format obsidian|logseq|joplin|notion] [--out DIR]`
  (default `--out`: `<from>-simpul`).
- `export-html <vault> <catatan> [--out path]`.
- `export-graph <vault> [--format json|graphml] [--out path]`
  (scan vault + `GraphCsr.build`, hormati vault terenkripsi via
  `SIMPUL_PASSWORD`).

### UI (`apps/agent_flutter`)

- **`ui/command_palette.dart`**
  - `PaletteAction(label, onSelected, {hint})`.
  - `showCommandPalette(context, actions)`: dialog filter fuzzy
    (case-insensitive substring, skor = posisi kemunculan, terurut naik);
    panah atas/bawah navigasi, Enter menjalankan, Esc menutup.
  - `PaletteShortcut`: `CallbackShortcuts` Ctrl+K / Ctrl+P.
- **Editor page**: Ctrl+K membuka palette berisi aksi tetap (toggle pratinjau,
  simpan, panel tautan) + "Buka: <path>" untuk seluruh catatan hasil
  `VaultScanner.scan`; tombol AppBar: palette, catatan baru dari template
  (pilih template, input judul, render variabel, tulis atomik
  tmp+rename, buka), ekspor HTML ke `<catatan>.html`.
- **Graph page**: Ctrl+K membuka palette "Buka: <path>" dari node graf.

## Catatan desain

- Impor tidak pernah menimpa vault tujuan secara destruktif; hasil selalu ke
  folder baru (default `<from>-simpul`).
- Ekspor HTML escape semua input sebelum inline formatting sehingga aman
  terhadap injeksi `<script>`.
- Ekspor graf membaca ulang vault (bukan cache) sehingga selalu konsisten
  dengan isi disk; vault terenkripsi tetap didukung lewat jalur crypto
  standar (fail-closed tanpa password).
- Palette tidak memegang state vault; daftar catatan di-scan saat dibuka
  sehingga selalu segar, dan kegagalan scan tidak memblokir aksi tetap.
