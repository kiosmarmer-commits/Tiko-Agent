## Arsitektur

### Core (`packages/simpul_core`)

- **`src/fuzzy.dart`**: `editDistance(a, b, {maxEdit})` banded Levenshtein O(n·maxEdit);
  `wordTokens` lowercase ASCII+Latin-1; `fuzzyMatches(words, term, {maxEdit})` —
  tolerance 0 berarti exact-only (tanpa false positive untuk kata pendek).
- **`src/vault_index.dart`**: `_score` kini memanggil `_fuzzyScore(note, term)`
  ketika exact match gagal; hanya di backend JSON — SQLite FTS5 tetap exact
  (fuzzy di sisi FTS membutuhkan trigram tokenizer; ditunda).
- **`src/saved_search.dart`**: `SavedSearch(name, query, createdAt)` + JSON;
  `SavedSearchStore.list/save/delete/resolve`; overwrite nama sama; sort by name.
- **`src/resource_monitor.dart`**: `ResourceSnapshot(rssMb, cpuCount, loadAvg1)`
  + `toJson`; `ResourceMonitor.isPluggedIn()` null-safe; `PowerSaverGate.allowsWork`
  = `!enabled || plugged != false` (fail-open untuk desktop tanpa sensor baterai).

### CLI (`apps/simpul`)

- `simpul search-save <vault> <nama> "kueri"` / `search-list` /
  `search-run <vault> <nama> [--limit N]` (JSON: name, query, hits
  path/title/score/snippet) / `search-delete`.
- `simpul resources` → JSON `rss_mb`, `cpu_count`, `load_avg_1`, `plugged_in`.

### UI (`apps/agent_flutter`)

- **`ui/note_chat_panel.dart`**: badge RAM (diambil sekali saat init via
  `ResourceMonitor.snapshot()`), tombol jeda AI-U03 (kirim dinonaktifkan +
  label "AI dijeda"), gate AI-U04 — `powerSaverEnabled` + `pluggedInOverride`
  (injeksikan untuk test); saat baterai: banner merah + kirim diblokir.
- **`ui/settings_store.dart`**: `AppSettings.powerSaver` (key `ui.powerSaver`,
  default false) + copyWith/load/save.
- **`ui/settings_view.dart`**: SwitchListTile "Mode hemat daya (AI-U04)".
- **`ui/note_editor.dart` + `main.dart`**: `powerSaverEnabled` diteruskan dari
  `AppSettings` ke editor page → panel chat.

## Catatan desain

- Fuzzy hanya di backend JSON; SQLite FTS5 tetap exact — konsisten dengan
  keputusan P0 (FTS5 dipakai apa adanya; trigram tokenizer menyusul bila perlu).
- `PowerSaverGate` fail-open ketika status daya tak diketahui (desktop/server
  tanpa `/sys/class/power_supply`) agar fitur tidak pernah memblokir pengguna
  yang tidak bisa dipastikan statusnya; pengguna tetap bisa mematikan mode ini.
- Kata pendek (≤4 huruf) tetap exact-only untuk menghindari false positive.
