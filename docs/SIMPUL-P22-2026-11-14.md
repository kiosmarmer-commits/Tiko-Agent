## Arsitektur

### Core (`packages/simpul_core/src/note_chat.dart`)

- `NoteChatScope { note, folder, vault }`; `ChatSource(path, headingPath, score)`;
  `NoteChatAnswer(answer, sources, contextTokens, scope)`.
- `NoteChatSession.ask(question, {scope, notePath, folder, confirmAsk})`:
  1. `VaultScanner.scan(vaultDir)` → kandidat per scope (folder: filter prefix +
     urut mtime, batas `maxFolderNotes`); vault: ranking leksikal judul+tag+alias.
  2. `preload()` membaca isi catatan kandidat (sekali per sesi).
  3. Cek kebijakan AI per catatan (AI-42): `allow` lolos, `ask` hanya dengan
     `confirmAsk: true`, `deny` ditolak — semua penolakan masuk audit (AI-43).
  4. Konteks dibangun dengan anggaran `maxContextChars` (default 8000),
     prompt menjawab dalam Bahasa Indonesia dan merujuk konteks.
  5. LLM via `OllamaChat` (injeksibel untuk test, tanpa jaringan saat uji).
- Token: estimasi ~4 karakter/token.
- `NoteChatInsertion.block(answer, {model, now})`: blok callout AI dengan
  penanda asal-usul (DIF-03) — aman disisipkan ke Markdown apa pun.

### UI (`apps/agent_flutter`)

- **`ui/note_chat_panel.dart`**: panel samping 320 px dengan dropdown cakupan,
  field pertanyaan, tombol kirim, jawaban `SelectableText`, daftar sumber,
  estimasi token, tombol sisip. `askOverride` untuk widget test (tanpa I/O —
  pelajaran P20: I/O nyata tidak pernah selesai di dalam FakeAsync).
- **Editor page**: tombol AppBar toggle panel chat (hanya saat catatan terbuka);
  `_insertAiBlock` menambahkan blok AI ke teks (satu langkah undo, dirty dot).
- **`ui/jank_monitor.dart`**: `JankMonitor` singleton + `JankBadge` overlay;
  toggle ikon speedometer di AppBar graph page (NFR-O01, mode pengembang).
- **`ui/index_dashboard.dart`**: `IndexStatusSummary.fromNotes` (murni, teruji)
  + `showIndexDashboard` dialog dengan tautan rusak disorot merah (NFR-O03).

## Catatan desain

- Fail-closed menyeluruh: policy rusak → `denyAll`; penolakan selalu menulis
  audit sebelum melempar; catatan yang ditolak tidak pernah mencapai model.
- Konteks vault memakai ranking leksikal deterministik (judul+tag+alias) tanpa
  embedding — tanpa dependensi baru dan bisa diuji offline; jalur RAG semantik
  yang sudah ada tetap dipakai lewat perintah `ask`/`semsearch` yang terpisah.
- Panel chat tidak pernah menulis ke catatan sendiri; penyisipan selalu lewat
  editor (satu langkah undo, tetap butuh simpan manual) sesuai AI-41.
