# Simpul Batch P5 — OllamaEmbedder (AI-03) + Korpus Evaluasi AI-E01/AI-E02

Tanggal: 2026-11-13. Batch kelima implementasi PRD "Simpul" di Tiko-Agent,
menyusul P0 (fondasi), P1 (layout + semantik hibrida), P2 (Louvain + sync +
saran tautan), P3 (quadtree culling + isolate + multi-level), P4 (MCP bridge +
cache graf).

## Cakupan

1. **`AsyncEmbeddingProvider`** (`packages/simpul_core/lib/src/embedding.dart`)
   — kontrak async baru untuk embedder berbasis server lokal/remote (AI-03):
   `embed`, `embedBatch`, `modelVersion`, `dimension`. Kontrak sinkron
   `EmbeddingProvider` tetap dipakai `HashingEmbedder`; vektor tersimpan tetap
   membawa `modelVersion` agar vektor lintas model tidak pernah bercampur
   (AI-13).
2. **`OllamaEmbedder`** (`packages/simpul_core/lib/src/ollama_embedder.dart`)
   — implementasi `AsyncEmbeddingProvider` untuk endpoint Ollama lokal
   (`POST <baseUrl>/api/embed`, body `{model, input: [texts]}` →
   `{embeddings: [[...]]}`):
   - Transport **injektable** (`fetch`) sehingga seluruh test berjalan tanpa
     jaringan; default `HttpClient` POST JSON.
   - Fail-closed menyeluruh: non-200, timeout (default 30s → StateError),
     jumlah vektor ≠ jumlah input, entri bukan array, dimensi ≠ `dimension`
     (default 768, divalidasi per vektor), norm 0 → semua `StateError`.
   - L2-normalize manual; `modelVersion = 'ollama:<model>'` sehingga indeks
     vektor hashing dan ollama tidak pernah tercampur.
   - `embedBatch` satu round-trip per panggilan (AI-12).
3. **Korpus evaluasi AI-E01 lite**
   (`packages/simpul_core/lib/src/eval_corpus.dart`) — mini-vault
   deterministik 42 catatan (7 topik × 6 subtopik: machine-learning, cooking,
   football, personal-finance, travel, health, programming) ditulis dwibahasa
   Indonesia+Inggris, plus **28 kueri gold** (4 per topik, selang-seling ID/EN,
   parafrasa lintas-bahasa disengaja) dengan gold path `eval/<topik>/<slug>.md`.
4. **`EvalHarness`** — ranking cosine deterministik (vektor L2-normalized →
   dot product), tie-break indeks naik; metrik **recall@k** (default k=5) dan
   **MRR** (AI-E02). `EvalHarness.run` sinkron (HashingEmbedder);
   `EvalHarness.runAsync` batch lewat `AsyncEmbeddingProvider` (Ollama).
5. **CLI `simpul eval`** (`apps/simpul/bin/simpul.dart`) —
   `simpul eval [--embedder hashing|ollama] [--model M] [--base-url U]
   [--dim N] [--k K]`; output JSON metrik; embedder tidak dikenal dan kegagalan
   Ollama → exit non-zero (fail-closed).
6. **Test** — `test/ollama_embedder_test.dart` (9 kasus: L2-normalized,
   urutan batch, kosong tanpa transport, dimensi salah, norm 0, jumlah salah,
   HTTP 500, timeout, JSON non-map) dan `test/eval_test.dart` (5 kasus:
   konsistensi korpus, determinisme, threshold baseline, relasi recall@1 ≤
   MRR, `runAsync` ≡ `run`).

## Keputusan arsitektur

- **Mengapa `AsyncEmbeddingProvider`, bukan memaksakan `EmbeddingProvider`?**
  `EmbeddingProvider.embed` sinkron dipakai luas (`SemanticIndex`,
  `InMemorySemanticIndex`, `HybridSearch`) dan `HashingEmbedder` memang
  deterministik sinkron. HTTP tidak mungkin sinkron di Dart, jadi memaksa
  `OllamaEmbedder implements EmbeddingProvider` berarti bug (Future tidak
  di-await). Pemisahan antarmuka menjaga call-site sinkron tetap bebas
  perubahan, dan adapter sinkron→async tetap bisa diuji.
- **Bug ranking harness ditemukan saat review**: versi awal membandingkan
  cosine antar catatan (`vectors[b].cosine(vectors[a])`) sehingga vektor kueri
  tidak pernah dipakai. Kini skor = dot(query, note), diurutkan menurun,
  tie-break indeks.
- **`Float32List.cosine` tidak ada** di `embedding.dart` (hanya
  `QuantizedVector.cosine`); harness menghitung dot product manual — sah karena
  seluruh vektor dijamin L2-normalized.
- **Threshold test dikalibrasi dari hasil terukur**, bukan aspirasi: baseline
  `hashing-v1` pada korpus ini = recall@5 **0.893**, MRR **0.787**; test
  menegakkan recall@5 ≥ 0.85 dan MRR ≥ 0.75.
- **3 kasus meleset dari top-5** (`overfitting`, `budget-backpacking`,
  `garbage-collection`) — semuanya parafrasa tanpa overlap leksikal dengan
  teks catatan. Ini justru bukti kebutuhan AI-03: embedder semantik nyata
  (nomic-embed-text dsb.) diharapkan menutup kasus-kasus ini; `simpul eval
  --embedder ollama` menyediakan jalur pengukurannya (ADR-06).

## Hasil baseline (sandbox, 2026-11-13)

```
$ dart run bin/simpul.dart eval
{"model":"hashing-v1","cases":28,"k":5,"recall_at_k":0.8928571428571429,"mrr":0.7871222527472527}
```

- `simpul eval --embedder ollama` tanpa server → exit 1 dengan pesan
  kegagalan koneksi (fail-closed, diverifikasi).

## Traceability PRD

- **AI-03** (embedding lokal via server): `OllamaEmbedder`.
- **AI-12** (batching): `embedBatch` / `runAsync` satu round-trip.
- **AI-13** (versi model): `modelVersion = 'ollama:<model>'` vs `hashing-v1`.
- **AI-E01** (korpus evaluasi): `EvalCorpus` 42 catatan / 28 kueri gold.
- **AI-E02** (metrik): recall@k + MRR di `EvalHarness`, CLI `eval`.
- **ADR-06** (keputusan ONNX vs server): jalur ukur Ollama kini ada; hashing
  tetap default karena tanpa unduhan model.
