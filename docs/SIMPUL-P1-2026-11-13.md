## Layout Barnes-Hut (GRA-L01)

- Quadtree dengan kriteria pembukaan `width/dist < theta` (default 0.9) —
  O(n log n) per iterasi, bukan O(n²).
- Gaya: repulsi Coulomb lembut `repulsion/(d²+1)`, pegas Hooke
  `springStrength*(d−springLength)` per edge CSR, tarikan pusat.
- Integrasi Euler dengan damping dan **cooling schedule kuadratik**
  (`temp = max(0.01, maxStep*(1−t)²)`) — kecepatan dibatasi `temp`, sehingga
  simulasi dijamin tidur (GRA-L03) sebelum `maxIterations`.
- Deterministik penuh: spiral golden-angle untuk inisialisasi, jitter
  deterministik untuk posisi duplikat, tanpa RNG.
- Posisi ditulis balik ke buffer `Float32List` milik `GraphCsr`
  (GRA-D01/GRA-L06); memanggil `simulate` lagi dengan `warmStart: true`
  melanjutkan dari posisi tersimpan (GRA-L02).

## Search semantik hibrida (AI-11..14, AI-20, AI-30)

- `EmbeddingProvider` antarmuka dapat diganti (pola AI-03). Implementasi P1:
  `HashingEmbedder` — feature hashing atas unigram, bigram, dan karakter
  trigram (`\p{L}` unicode, bahasa-agnostik untuk Indonesia/Inggris),
  L2-normalized, tanpa unduhan model (selaras AI-02).
- **AI-14**: vektor disimpan sebagai `Int8List` (skala tetap 1/127 karena
  input ternormalisasi); cosine dihitung langsung di atas int8.
- **AI-12**: `upsert` menyimpan hash per chunk; chunk dengan hash sama tidak
  pernah di-embed ulang (diverifikasi test dengan embedder penghitung).
- **AI-13**: `model_version` disimpan bersama vektor; file persistensi dengan
  versi berbeda diabaikan, tidak pernah tercampur.
- **AI-30**: `search(allowedPaths: …)` memindai subset terfilter saja.
- **AI-20**: `HybridSearcher` menggabungkan hasil leksikal (FTS5/bm25 atau
  JSON scoring) dan semantik dengan RRF `1/(k+rank)`, `k=60`; snippet dan
  judul dipertahankan dari sisi leksikal.

### ADR-06 (keputusan ANN, terbuka untuk BM-07 skala penuh)

**Keputusan P1: brute-force cosine di atas vektor int8 terkuantisasi, tanpa
ANN.** Alasan:

1. PRD `05` §2.4 mencatat `sqlite-vec` sendiri melakukan brute-force; tidak
   ada keuntungan ANN pada skala ini.
2. Pengukuran awal (366 chunk): p50 270 µs, p95 391 µs — jauh di bawah target
   p95 < 300 ms (AI-30). Ekstrapolasi linear ke 1 juta chunk ≈ 0,7–1 dtk;
   prefilter (folder/tag/BM25 kandidat) menurunkannya lagi.
3. Kuantisasi int8 memberi ~8× penghematan memori dengan recall@10 = 0.9
   terhadap ranking full-precision (diukur BM-07).
4. ANN (HNSW/IVF) dievaluasi ulang hanya bila BM-07 pada 1–10 juta chunk
   melanggar target — sesuai AI-31.

## Update inkremental (NFR-08, BM-04)

`VaultIndex` mendapat `upsert(List<IndexedNote>)` dan `removePaths(List<String>)`:

- SQLite: transaksional; children (chunks/fts/tags/props/links) catatan yang
  diganti dibuang lalu dibangun ulang; `PRAGMA foreign_keys = ON` untuk
  cascade; resolusi link terhadap notes existing + yang baru masuk.
- JSON: pemetaan by-path + flush atomik tmp+rename.
