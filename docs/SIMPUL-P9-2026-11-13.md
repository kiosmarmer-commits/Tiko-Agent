# Simpul Batch P9 — Enkripsi Vault M1: Indeks Terenkripsi (SEC-03/05/07–12)

Tanggal: 2026-11-13. Batch kesembilan implementasi PRD "Simpul", menutup
kebutuhan keamanan MUST dari `06-enkripsi.md` untuk **Mode M1**: file `.md`
tetap polos (definisi M1), sedangkan seluruh artefak indeks terenkripsi.

## Prinsip (sesuai PRD)

Tidak menciptakan kriptografi sendiri. Semua primitif dari pustaka
`cryptography` 2.9.0 (pure Dart, teruji): AEAD **XChaCha20-Poly1305**
(SEC-03) dan KDF **Argon2id** (SEC-05). Parameter default mengikuti panduan
OWASP memory-hard: 19 MiB, t=2, p=1, salt 16 byte.

## Hierarki kunci (SEC-07)

```
password ──Argon2id(salt)──▶ KEK ──wrap──▶ vault key (.simpul/vault-key.crate)
vault key ──wrap──▶ DEK per file (acak 32 byte per enkripsi)
DEK ──XChaCha20-Poly1305(nonce acak)──▶ isi file
```

- **SEC-08**: nonce baru via `Random.secure()` untuk setiap enkripsi (satu-
  satunya pengecualian yang disengaja dari konvensi determinisme repo —
  kebutuhan kriptografis, diuji eksplisit).
- **SEC-09**: format crate berversi —
  `magic(8)='SMPLCRT1' | versi(1) | algo AEAD(1) | KDF(algo(1) m(4 LE) t(4 LE)
  p(1) saltLen(1) salt) | kunci terbungkus(len(2 LE) nonce(24) mac(16) ct) |
  nonce(24) | mac(16) | ciphertext`. Satu format untuk key crate (payload =
  vault key, dibungkus KEK) dan file data (payload = isi file, DEK dibungkus
  vault key). Parameter KDF tersimpan di header tiap crate sehingga kunci
  lama tetap terbuka setelah default berubah.
- **SEC-I04**: kegagalan MAC (`SecretBoxAuthenticationError`) dipetakan ke
  `VaultCryptoException` — data rusak / kata sandi salah gagal tertutup.

## Komponen baru

1. **`vault_crypto.dart`** (simpul_core) — `KdfParams`, `VaultCryptoException`,
   `VaultCrypto` (`create`, `open`, `sealKeyCrate`, `encryptBytes`,
   `decryptBytes`, `encryptFileInPlace`, `decryptFileInPlace`,
   `looksEncrypted`, `isFileEncrypted`, `writeBytesAtomically`), dan
   **`VaultFiles`** — lapisan I/O fail-closed: membaca file crate tanpa kunci
   melempar `VaultCryptoException` (bukan diam-diam mengembalikan
   ciphertext), menulis selalu atomik tmp+rename.
2. **`JsonVaultIndex`** — menerima `VaultCrypto?`; keempat titik I/O
   (`index.json`, `graph_cache.json`) lewat `VaultFiles`. `catch (_)` lama
   yang menelan semua error kini **me-rethrow `VaultCryptoException`**
   (fail-closed) sementara korupsi polos tetap ditoleransi seperti sebelumnya.
3. **`InMemorySemanticIndex`** — sama, untuk `vectors.json` (SEC-12);
   `storedModelVersion(path, {crypto})` membaca file terenkripsi.
4. **`openVaultCacheStore`** — menerima `crypto` sehingga cache layout
   (SEC-11) ikut terenkripsi.
5. **CLI** (`apps/simpul`):
   - `simpul lock <vault>` — enkripsi in-place `index.json`, `vectors.json`,
     `graph_cache.json`, tulis `.simpul/vault-key.crate` + penanda mode
     `.simpul/vault-mode.json` (`{mode:'m1', kdf, created_at}`). Menolak
     backend SQLite dengan pesan jelas (SQLCipher belum tersedia) dan vault
     yang sudah terkunci.
   - `simpul unlock <vault>` — dekripsi balik, hapus crate + penanda mode.
   - `simpul vault-status <vault>` — mode, parameter KDF, status per file.
   - Semua perintah lain membaca `SIMPUL_PASSWORD` otomatis saat vault
     terkunci; tanpa password, operasi gagal dengan pesan "vault terkunci"
     (fail-closed).
6. **Bridge MCP** — `_openIndex`/`_semsearch` mendeteksi mode terkunci;
   `SIMPUL_PASSWORD` dari environment; tanpa password, tool call mengembalikan
   `isError` dengan pesan jelas.

## Keputusan desain

- **Password dari env `SIMPUL_PASSWORD`**, bukan prompt — bridge berjalan
  headless dan CLI dipanggil skrip; prompt interaktif tidak sesuai pola
  lokal-first yang ada.
- **`ai-permissions.json` tetap polos**: dibaca sebelum unlock (kebijakan
  pra-unlock) dan tidak memuat konten vault.
- **Audit log belum terenkripsi** di P9 — JSONL append-only tanpa konten;
  enkripsi penuh menyusul bersama M3 (T-06).
- **Auto-lock (SEC-16)**: proses CLI berumur pendek memegang kunci hanya di
  memori selama proses hidup; bridge berumur panjang adalah limitasi yang
  didokumentasikan (auto-lock UI-layer belum ada).
- **SQLite ditolak pada vault terkunci** (bukan diam-diam polos): SQLCipher
  belum tersedia; pengguna diarahkan ke backend JSON.
