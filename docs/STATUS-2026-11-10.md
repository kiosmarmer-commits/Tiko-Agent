## Batasan yang sengaja belum diklaim selesai

- GET SSE saat ini menangkap notifikasi dan mengobservasi JSON-RPC server request yang membawa ID. Agent belum mengeksekusi atau menjawab request itu. Reconnect/resume/cursor belum diimplementasikan.
- Retry HTTP MCP hanya berlaku terbatas untuk read-only JSON-RPC methods pada network exception atau status 408/425/429/502/503/504, dengan maksimal 2 retry default (dapat diatur per server melalui `max_read_retries: 0..3`). `tools/call` dan notifications tidak di-retry. OAuth dynamic client registration belum tersedia; auth saat ini menggunakan header SecretRef statis.
- URL MCP HTTP masih merupakan konfigurasi admin tepercaya; SSRF/DNS rebinding guard belum diterapkan pada jalur ini. URL credentials/fragments/control chars ditolak, namun ini bukan pengganti pembatasan akses jaringan dan konfigurasi.
- `agent_providers.CircuitBreaker`/`BreakerLlmProvider` masih merupakan API legacy yang diekspor; composition root aktif menggunakan health state Router, tidak memasang wrapper kedua.
- Feedback skill belum terhubung end-to-end ke API/UI. Email masih outbound-only. Android scaffold/build, inbound email receiver, integrasi credentials nyata, dan pengujian Termux/perangkat nyata masih terbuka.
