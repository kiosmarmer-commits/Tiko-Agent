# Simpul Batch P12 — Watcher File (NFR-S05) & Aturan `ai-access` Frontmatter (AI-42)

Tanggal: 2026-11-14. Batch keduabelas implementasi PRD "Simpul", menutup dua
item backlog: sinkronisasi otomatis saat catatan berubah, dan izin AI
per-catatan lewat frontmatter (sebelumnya hanya config file — limitasi yang
tercatat di P7).

## Komponen baru / berubah

1. **`vault_watcher.dart`** (simpul_core, baru) — `VaultWatcher`:
   - Polling snapshot diff (mtime+size per catatan) per interval, bukan
     inotify. Alasan terverifikasi di sandbox: filesystem virtiofs tidak
     mendukung inotify rekursif (event hanya untuk folder yang ditonton
     langsung) — dan vault Obsidian memang sering berada di folder
     tersinkron/jaringan (NFS, cloud sync) dengan keterbatasan sama. Polling
     bekerja di semua filesystem, desktop, mobile, dan Termux.
   - `batches({interval})` — stream batch `VaultWatchBatch` (path relatif
     terurut, termasuk penghapusan); tick kosong dilewati; dibatalkan dengan
     bersih lewat `StreamController` + `Timer.periodic`.
   - Folder tersembunyi (`.obsidian`, `.simpul`, `.git`) dan non-`.md`
     diabaikan sehingga tulisan indeks/vektor tidak pernah memicu watcher
     itu sendiri.
2. **CLI `simpul watch <vault> [--interval-ms N]`** — daemon sinkron
   inkremental otomatis (NFR-S05): satu baris JSON per sinkronisasi
   (`changed` + payload `sync` lengkap), flush per baris, membaca
   `SIMPUL_PASSWORD` untuk vault terkunci seperti perintah lain. Logika sync
   direfaktor ke `_syncOnce` dan dipakai bersama `sync`.
3. **`ai-access` frontmatter (AI-42)** — aturan per-catatan:
   - `NoteParser` mengekstrak `ai-access`/`ai_access` → `ParsedNote.aiAccess`
     (`allow`/`ask`/`deny`; nilai tidak dikenal → `ask`).
   - `IndexedNote.fromParsed` meneruskannya ke skema `ai_access` yang sudah
     ada sejak P0 (JSON maupun SQLite).
   - `AiAccessPolicy.decide` menerima `noteAiAccess` — aturan note-level
     digabung most-restrictive dengan semua layer config. Hanya `izin`/`tolak`
     eksplisit yang menjadi aturan; `tanya`/nilai tak dikenal/absen berarti
     tanpa aturan note-level (kompatibel dengan indeks lama yang tersimpan
     sebagai `ask`).
   - Bridge `_decide` kini membaca `note.aiAccess` dari indeks sehingga
     `read_note`, `search` (filter), dan `ask_vault` (prefilter) mematuhi
     aturan frontmatter.
4. **`VaultModes.noteFiles`** kini publik (dipakai test bridge M3 yang
   disederhanakan memakai `VaultModes.lock` sungguhan).
