# SIMPUL-P20 — Editor Catatan + Panel Backlink (2026-11-14)

Batch ini menuntaskan gap fungsional inti terbesar PRD `rnd/obsidian` yang belum
tersentuh: sebelumnya Simpul sepenuhnya read-only (index, graph, search, sync,
TUI) tanpa kemampuan mengedit catatan.

## Arsitektur

### Core — `packages/simpul_core/lib/src/note_editor.dart` (baru, pure Dart)

- `VaultLinkResolver(List<ScannedNote>)`: lookup dua-pass (path, basename,
  judul, alias → path vault) sehingga referensi maju tetap resolve;
  `resolve(target)`, `completions(token)` (skor: prefix basename → prefix
  judul → contains), `backlinks` (map path → sumber terurut).
- `NoteEditor`: `load`, `text` setter (satu entri undo per panggilan), `edit`,
  `undo`/`redo`, `dirty`, `save()` atomik, `insertWikilink(offset, target,
  {alias})` (mengembalikan offset kursor baru), `links()` (klasifikasi
  resolved/unresolved dari `NoteParser.parse`), `backlinks()`.
- UI-free sehingga dipakai bersama klien Flutter dan host CLI berikutnya.

### UI — `apps/agent_flutter/lib/ui/note_editor.dart` (baru)

- `SimpulNoteEditorPage`: field vault + path, AppBar (undo, redo, toggle
  pratinjau, simpan dengan indikator titik oranye saat dirty).
- Autocomplete `[[`: listener controller mendeteksi `[[token` di posisi kursor
  dan menampilkan panel kandidat; tap mengganti token dengan `[[path]]` dalam
  satu langkah undo.
- Panel `ExpansionTile` "Tautan (FR-20/21)": backlink + tautan keluar
  (resolved bisa ditap untuk membuka catatan lain; unresolved merah).
- `MarkdownPreview`: renderer minimalis — heading 1–6, code fence, blockquote,
  daftar/checkbox, bold/italic/inline-code, wikilink (warna aksen), link md.
- Tema memakai `SimpulTheme` (`context.simpulPanel/Border/Accent/Muted/Danger`)
  agar konsisten lintas platform (lanjutan P18).

### Integrasi

- `graph_view.dart`: `_openNote` kini membuka editor (sebelumnya dialog
  read-only).
- `main.dart`: menu "Editor Catatan (Simpul)" di halaman More, memakai
  `settings.vaultPath` sebagai vault awal.
