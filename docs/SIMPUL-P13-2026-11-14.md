## Detail teknis

- **Kamera animasi**: `_GraphViewState` kini memakai `TickerProviderStateMixin`;
  `cameraRequest` dari controller dikonsumsi menjadi target `Matrix4`
  (`translate(w/2, h/2) · scale(s) · translate(-x, -y)`) dan dianimasikan 250 ms.
  `Matrix4.translate/scale` yang deprecated diganti `translateByDouble`/`scaleByDouble`.
- **Tap komunitas**: hanya aktif pada LOD aggregate; fallback ke seleksi node biasa
  bila tidak ada centroid dalam radius tap.
- **Dimming memakai `visibleIds`**: saat filter kosong `visibleIds` = semua node,
  sehingga tanpa filter tidak ada perubahan tampilan.
- **Cache picture** disimpan di controller (`staticPicture`, `staticViewport`,
  `staticScale`, `staticFilterVersion`, `staticGraphVersion`) dan dibuang di
  `dispose()`; picture lama dibuang setelah rekaman baru selesai.
- Path LOD aggregate tetap digambar langsung (tanpa cache) karena berbasis komunitas.

## Batasan

- Animasi kamera 250 ms tetap (bukan durasi adaptif); cukup untuk vault ukuran besar
  karena hanya interpolasi matriks, bukan re-layout.
- Slider fisika memicu layout ulang penuh saat dilepas (`onChangeEnd`), memanfaatkan
  warm-start cache (GRA-L02) agar cepat.
- Timeline memakai mtime file (`mtimeNs`); tidak ada histori revisi per-catatan.
