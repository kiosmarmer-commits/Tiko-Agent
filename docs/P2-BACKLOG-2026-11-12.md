## Batasan yang dicatat

- `execute_code` bukan interpreter kode — program adalah urutan tool call data-driven; eksekusi kode arbitrer tetap di sandbox shell (`shell` + jail policy).
- `tool_search` tersedia sebagai meta-tool; subset skema otomatis ke model kini **tuntas** — `RuntimeContext` mengirim top-k specs relevan + `tool_search` bila registry > threshold (lihat `DEFERRED-COMPLETION-2026-11-12.md`).
- Worktree tidak mendelete branch saat remove (branch `tiko/<task>` dipertahankan untuk review).
- OTel: batch di-flush on-size (32 span) dan saat close; retry/backoff belum ada (best-effort by design). Metrics in-process (`Metrics`) tetap sumber angka ringkasan.
