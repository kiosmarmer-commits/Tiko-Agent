                            GATEWAYS

                            Channels

                            Status channel gateway yang hidup di daemon dan env yang mengaturnya.

                              Setup channel

                              Channel diaktifkan lewat variabel env saat daemon start (config immutable). Setelah env diset, restart daemon; token/nilai rahasia tidak pernah ditampilkan di sini.

                              SCHEDULER

                              Automation

                              Cron job terjadwal di daemon (disimpan durabel di jobs.json).

                              Buat cron job

                              Cron wajib 5 field; prompt dijalankan scheduler daemon pada jadwal (tick sekitar 20 detik). missed_policy default run_once.

                                SECURITY

                                Security Center

                                Status keamanan runtime: safe mode/panic, sandbox, consent plugin, token anomaly, guard, dan audit terakhir (read-only).

                                Batasan

                                Security Center read-only: tidak ada toggle safe mode/panic atau kill switch dari GUI. Counter guard dihitung in-memory (reset saat daemon restart), tanpa nilai rahasia — hanya flag sealed storage.

                                  AUDIT

                                  Audit query browser

                                  Cari entri audit runtime per tool/session/risk/verdict/taint — read-only, entri sudah teredaksi.

                                  Filter

                                  Maksimal 50 entri diambil per halaman (buffer in-memory + file JSONL 7 hari terakhir, dedupe). Gunakan tombol Berikutnya untuk halaman berikutnya.

                                    WORKSPACE

                                    Artifacts

                                    Browser file workspace read-only + diff versus versi terakhir (`.bak` dari write_file). Path divalidasi PathSafety fail-closed.
