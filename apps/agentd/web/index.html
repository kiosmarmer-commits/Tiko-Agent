          GETTING STARTED

          Bantuan & koneksi

          Panduan singkat untuk menjalankan Tiko.

          Mulai cepat

          1. Jalankan daemon dengan opsi --api.
          2. Ambil token dari data/api.token pada perangkat tepercaya.
          3. Masukkan API base dan token di bagian Setelan koneksi.
          4. Kembali ke Chat dan mulai percakapan.

          Keamanan

          Tindakan berisiko harus melalui approval. Jangan bagikan token API, terutama saat memakai koneksi di luar perangkat lokal.

          Setelan koneksi

          Token disimpan pada penyimpanan browser di perangkat ini. Hindari menggunakan perangkat bersama.
